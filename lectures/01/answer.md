## 演習

- 講座に固有の質問（宿題の3レベル）へのモデルの回答（要約でよい）：
  gemini-3.5-flash-lite・gemini-3.8-flash とも、「分からない」とは答えなかった。「おそらく」「一般的に」と前置きしたうえで、「レベル1：基礎（穴埋め・コードを動かす）、レベル2：応用、レベル3：発展（ゼロから実装）」のような難易度別の一般論を具体的に説明した。3.8-flash は3回とも「AI活用の深度」という別パターンも併記した。どちらも最後に講座資料の確認を勧めた。
- 用語集の正しい意味と比べて気づいたこと：
  正解（基礎・実装・発展から1つ選べば完了）と一致した回答は 6 回中 0 回。レベル名の「基礎」「発展」が偶然一致した回があり、知らずに読むと正しく見えてしまう。また「全員レベル2まで必須が多い」（flash-lite run2）、「レベル1が修了の最低条件となることが多い」（3.8-flash run1）など、実際のルールと食い違う内容を一般論として断定していた。学習データにない情報には、もっともらしい答えを作ることが確認できた。
- 表示できたトークン数（入力 / 出力）：
  入力 21 / 出力 582（gemini-3.5-flash-lite、講座固有の質問「3レベル」を1回実行）

## 宿題

- 取り組んだレベル：基礎
- やったこと：
  - 2つの質問を、モデルを変えて各3回ずつ実行した（計12リクエスト）。
    - Q1「LoRA とは何ですか？」（一般的な用語）
    - Q2「AIE2026 の講座の宿題にある「3レベル」とは何ですか？」（講座固有のこと）
  - 使ったモデル：gemini-3.5-flash-lite、gemini-3.8-flash（`AIE_MODEL` で切り替え。temperature 等はデフォルト）
  - レート制限を避けるため各実行の間に15秒待った。12回ともエラー（429 / 503）は出なかった。
  - ログは `lectures/01/logs/run.txt` に保存した。
- 結果：
  - Q1（LoRA）：両モデルとも6回すべて要点は正しかった（Low-Rank Adaptation の略、元モデルを凍結して小さな追加パラメータだけを学習、ファイルが小さく付け替え可能）。
    - 3.8-flash は3回とも「2021年に Microsoft の研究者が提案」と出典に触れ、「重みの更新分を2つの小さな行列の積で近似する」と仕組みまで説明した。flash-lite は出典に触れず、「付け足しパーツ」「付箋」など比喩が中心だった。
    - flash-lite には誤りがあった。run1 に意味の通らない文（「数十分の1〜数分の一のギガバイト単位」）、run3 に用語の誤記（「カタストロフィック・フォアフッティング」）と「劣化を防げる」という言い過ぎ。3.8-flash には目立った誤りはなかった。
    - 学習パラメータの割合などの数値は、両モデルとも実行ごとに変わった（「1%未満」「0.1%〜1%」「1/100〜1/10,000」など）。回答の構成（定義 → 課題 → 仕組み → メリット → 活用例）は毎回ほぼ同じだった。
  - Q2（3レベル）：両モデルとも 0 / 3（演習欄に記載）。
- 気づき・疑問：
